# YouTube Видео Загрузчик

Веб-приложение для загрузки видео с YouTube, построенное на Flask и pytube.

## Особенности

- 🎬 Скачивание видео с YouTube
- 📱 Адаптивный веб-интерфейс
- 📊 История последних загрузок
- 💻 Локальный сервер (работает без интернета)

## Установка

1. Установите Python 3.7+

2. Создайте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

```bash
python app.py
```

Сервер запустится на `http://127.0.0.1:5000`

## Использование

1. Откройте браузер и перейдите по адресу `http://localhost:5000`
2. Вставьте ссылку на YouTube видео
3. Нажмите "Скачать видео"
4. После загрузки нажмите ⬇️ Скачать видео для сохранения файла

## Структура проекта

```
video-downloader-app/
├── app.py              # Основной код приложения
├── templates/
│   └── index.html      # Веб-интерфейс
├── downloads/          # Папка для скачанных видео
├── requirements.txt    # Зависимости
└── README.md           # Документация
```

## Выходные данные

Видео сохраняются в папке `downloads` с именем вида:
`Название_20260804_153022.mp4`

## Важные замечания

- Приложение работает локально, не требует интернета
- YouTube видео должны быть доступны (не заблокированы в вашем регионе)
- Для скачивания некоторых видео может потребоваться установка SSL-сертификатов
